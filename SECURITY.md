# Security Policy

Do not file secrets, API keys, payment identifiers, customer data, or
credential-bearing webhook payloads in public issues.

For a security concern in this Buildathon repository, contact the maintainer
privately through the GitHub profile associated with the repository. Include a
minimal reproduction and redact all payment and credential material.

The Buildathon environment is local and credential-free. It must not be
treated as an authorization to use real payment credentials or move money.
